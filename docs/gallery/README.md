# Gallery

`index.json` lists the four programs under `examples/`. `playgroundUrl` is a
path on `pythsol serve` (`GET /examples/<id>`). There is no hosted playground.

`tests` is `passing` because the repo suite runs these programs in LiteSVM
and `pythsol test` runs the matching init templates. This file is not a claim
that a weekly gallery job exists, and it is not a list of twenty examples.
