Write Solana programs in Python.

PythSol checks a typed Python subset, lowers it to C, and compiles native SBF bytecode plus an Anchor-style IDL and a solders client. Nothing here runs your code.

counter.py — you write

@instruction
def increment(authority: Signer, counter: Mut[Counter], by: u64) -> None:
    """Add `by` to the count; only the stored authority may call this."""
    require(counter.authority == authority.key, CounterError.Unauthorized)
    counter.count += by

counter.c — the compiler writes

static uint64_t pyf_increment(RtCtx *rt) {
    if (rt->data_len != 8u) {
        rt_fail_log(1u, "counter.py", 49u, "instruction data length is wrong");
        return 1u;
    }
    uint64_t dp_by = 0u;
    rt_ld_u64(rt->data, 0u, &dp_by);
    if (!rt_owner_eq(acc_counter, rt->program_id)) {
        rt_fail_log(1003u, ...);
        return 1003u;
    }
    if (!rt_disc_eq(acc_counter->data, RT_DISC_COUNTER)) {
        rt_fail_log(1005u, ...);
        return 1005u;
    }
    if (!(rt_key_eq((const SolPubkey *)
                    (acc_counter->data + 8u), acc_authority->key))) {
        rt_fail_log(ERR_COUNTERERROR_UNAUTHORIZED, ...);
        return ERR_COUNTERERROR_UNAUTHORIZED;
    }
    uint64_t rt_t2 = 0u;
    rt_ld_u64(acc_counter->data, 40u, &rt_t2);
    uint64_t rt_t3;
    uint64_t rt_t4 = rt_checked_add_u64(rt_t2, dp_by, &rt_t3);
    if (rt_t4 != RT_OK) {
        rt_fail_log(rt_t4, "counter.py", 52u, "checked add (u64)");
        return rt_t4;
    }
    rt_st_u64(acc_counter->data, 40u, rt_t3);

Both chunks are real: the four Python lines above are pulled from examples/counter and the C is what our compiler emits for them — accounts role-checked, discriminators verified, arithmetic overflow guarded, and each failure attributed to a source line.

What PythSol gives you

Checked, not executed

The site parses your AST and type-checks accounts, seeds, and lamports — your Python is never executed by the playground.

Native, not WASM

clang targets the Solana SBF backend directly, so the artifact is a real deployable program with verifiable bytecode.

The workflow included

LiteSVM tests, deploy, faucet, wallet, verify, profiling, and a generated solders client ship with the CLI — no extra glue.
