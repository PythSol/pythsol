Still ahead:

- Data enums and `Vec` (they are not fixed-width).
- A hosted Pyodide playground and a networked compile sandbox.
- A deployed docs site, Pagefind CI, and an accessibility run.
- More than the four examples in `docs/gallery/index.json`.

Not scheduled: documentation translations, comprehension syntax, a second IR,
and in-browser SBF compilation.

`verify`, `profile`, `idl-publish`, `cpi`, and the VS Code extension exist in
this tree. An audit and a compute-unit regression gate do not.
