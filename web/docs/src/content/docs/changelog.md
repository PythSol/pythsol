`CHANGELOG.md` at the repository root is the changelog. `0.1.1` is the
current PyPI release (`pip install pythsol`); `0.1.0` was the first public
package. `0.1.1` fixes the install copy that shipped in `0.1.0` — the
installed landing page and docs now teach the PyPI install.

Everything after the compiler's token CPI, including `pythsol test`, the
cache, wallet, faucet, deploy, port, verify, profile, serve, and this site,
is packaged in `0.1.1` and listed under **Unreleased** in the root changelog
until the next feature release.
