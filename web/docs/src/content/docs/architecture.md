The repository file `docs/architecture.md` is the architecture note: the
pipeline, the phase table, emit invariants, and the product commands (cache,
test plugin, IDL CPI metadata, serve, verify, profile).

ADRs under `docs/decisions/` record the toolchain, LiteSVM, the light theme,
and the runtime ABI. This Starlight page does not replace those files.
